# シューベルト《アヴェ・マリア》の Realism — 岩の隠れ場からの光

この曲の原曲は《エレンの歌 第3番》D.839、作品52の6です。[新シューベルト全集の作品データベース](https://schubert-ausgabe.de/en/research/schubert-database/?FORM%5Bdetail%5D=475&cursor=925)は、スコットの詩とシュトルクのドイツ語訳を原詞として記録しています。[Oxford Song が掲載するドイツ語の歌詞](https://oxfordsong.org/song/ellens-gesang-iii)には、硬い岩、岩の裂け目、そこで庇護を願う祈りが現れます。なお、同ページ見出しの D.837 ではなく、作品番号は全集の D.839 に従っています。

現在の音源は歌唱ではなく、グロスヴェナーによるリストのピアノ編曲 S.558/12 です。[演奏家のアルバム紹介](https://www.benjamingrosvenor.co.uk/liszt)と[Decca の公式ブックレット](https://d24ku69pnn7av2.cloudfront.net/decca-classics-booklets/2021/GrosvenorLiszt_Booklet.pdf)でこの編曲を確認できます。映像はラテン語の典礼文を歌っている場面の再現ではなく、器楽編曲の背後にあるエレンの原詞から選んだものです。

硬い岩に守られた内側と、外から差すやわらかな光。その対比に、長い旋律に耳を澄ませながら庇護を求める静けさを託しました。人物の姿や聖母像は描かず、岩の入口と木立そのものを見つめます。これは映像のための解釈で、シューベルトやリストが訪れた場所、詩の舞台の正確な地形、歴史的な実写を示すものではありません。

## 動き

岩の輪郭、足元、樹幹とカメラの位置は固定し、入口の外の葉の一部と狭い範囲の薄明かりだけをゆっくり変化させます。岩全体を呼吸するように変形させたり、光を劇的に点滅させたりはしません。

写真調の生成画像に局所的な動きを加えたもので、実写動画や物理シミュレーションではありません。録音の拍とは同期せず、動きを減らす設定では静止します。素材や描画機能を利用できない場合は既存の代替描画に戻ります。
