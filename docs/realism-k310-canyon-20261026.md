# K.310 第2楽章 — 砂岩の曲線と差し込む光

モーツァルトのピアノ・ソナタ K.310 の第2楽章は、ヘ長調の Andante cantabile。穏やかな歌の中に強い表情の対比があることを、[モーツァルテウムの作品記録](https://kv.mozarteum.at/en/work/4054)と[ヘンレの校訂版序文](https://www.henle.de/media/46/a2/a5/1690886054/0396-1690886054-sync.pdf)で確認できます。

この Realism は、なめらかな砂岩の線を旋律の連続に、明るい差し込み光と深い影を内側の緊張に重ねた映像上の解釈です。[ナバホ・ネイションのアンテロープ・キャニオン](https://navajonationparks.org/navajo-tribal-parks/lake-powell/)に着想を得た生成景観で、特定の地点を記録した写真ではありません。モーツァルトがこの場所を訪れたり、曲の着想を得たりしたという意味でもありません。母の死をこの楽章の直接の原因とする説明も採りません。

岩、砂地、カメラは動かしません。光の方向を固定したまま、雲が日差しを弱めるような緩やかな明暗と、光の中のごく少数の塵の微動だけを加えています。岩が溶ける変形、光線の高速走査、画面全体の揺れはありません。

動きは共通の再生時刻に従い、停止・シーク・動きを減らす設定にも従います。音符や演奏の各場面との同期を装うものではなく、繰り返し可能な控えめな動きです。描画機能や画像の読み込みが利用できない場合は、従来の基本シーンへ戻ります。
