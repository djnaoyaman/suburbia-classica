# ピエ・イエスの Realism — 安息のための空間

「ピエ・イエス」は、慈しみ深いイエスに永遠の安息を願う祈りです。[バービカンの公演プログラム](https://www.barbican.org.uk/digital-programmes/insula-orchestraequilbey-faures-requiem)で原文と訳を確認できます。[ロサンゼルス・フィルの作品解説](https://www.laphil.com/works/requiem-op-48-1893-version)も、フォーレのレクイエムにおける静けさと慰めを伝えています。

砂時計で時間の終わりを強調する代わりに、何も急がずに休める小さな回廊と、空いた石の腰掛けを選びました。祈りの落ち着きを空間として受け止める映像解釈で、特定の葬儀、死者や実在の修道院を描いたものではありません。写真調の生成素材です。

## 動き

石のアーチ、腰掛け、床、背景、カメラは固定し、そばに下がる葉のごく一部分だけが弱い風で揺れます。建築が呼吸するような歪みや、劇的な光線の走査はありません。縦長画面では腰掛けと周囲の緑を近くに見る固定構図です。

録音の拍とは同期せず、動きを減らす設定では静止します。素材や描画機能が利用できない場合は、既存の代替描画に戻ります。
