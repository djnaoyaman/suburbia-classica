# ワルツ第9番の Realism — 音楽帖と戸口

[ショパン研究所の作品解説](https://chopin.nifc.pl/pl/chopin/kompozycja/73_walc-as-dur)は、1835年のドレスデンでの別れの際に、ショパンがこのワルツをマリア・ヴォジンスカへ贈った経緯を紹介しています。霜の模様よりも、曲に実際に結びつく「別れに残す音楽」を手がかりにしました。

閉じた音楽帖は残されるもの、半開きの戸とその先の道は離れていく方向。親しみを含む旋律と、そこに差す名残惜しさを、同じ画面にある静物と遠近に重ねた映像解釈です。帖は実際の贈り物の複製ではなく、部屋もドレスデンの実景ではありません。文字の読める偽の手紙や楽譜は描いていません。

## 動き

音楽帖、机、扉、道、カメラを固定し、戸口に下がる小さな葉の一部だけを弱い風で動かします。扉が自動で閉まったり、閉じた帖が演奏に合わせて動いたりはしません。写真調の生成素材を使い、縦長画面でも帖と外へ続く道を同時に見せます。

録音の拍とは同期せず、動きを減らす設定では静止します。素材や描画機能が利用できない場合は、既存の代替描画に戻ります。
