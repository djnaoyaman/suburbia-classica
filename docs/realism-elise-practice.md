# エリーゼのためにの Realism — 身近なピアノ

[ベートーヴェン・ハウスの作品解説](https://www.beethoven.de/de/work/view/5327609864912896/Bagatelle%20f%C3%BCr%20Klavier%20(a-Moll)%20WoO%2059?fromArchive=6299845270700032)は、この小品の成立を1810年としつつ、題名に登場する「エリーゼ」の特定には不確かさがあると説明しています。そこで特定の女性の肖像や、確認できない恋物語を描くのではなく、ピアノの小品が持つ身近な親密さに立ち戻りました。

飾りの少ない部屋の小さなアップライトと窓辺の薄い布は、穏やかな主題に何度も戻ってくる感覚を、いつも戻れる練習の場所に重ねた映像解釈です。ベートーヴェンの部屋や所有楽器、作曲時の場面を再現したものではなく、写真調に生成した現代的な情景です。

## 動き

ピアノ、椅子、床、窓枠、カメラは固定し、窓辺の布の一部分だけが弱い風でわずかに揺れます。鍵盤は閉じたままで、自動演奏や録音に合わせた演奏動作を装いません。縦長画面は、布とピアノの近い部分を見せる固定構図です。

録音の拍とは同期せず、動きを減らす設定では静止します。素材や描画機能が利用できない場合は、既存の代替描画に戻ります。
