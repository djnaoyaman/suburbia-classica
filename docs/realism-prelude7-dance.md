# 前奏曲第7番の Realism — 踊り出す前

[ショパン国際ピアノコンクールの作品解説](https://www.chopincompetition.pl/en/compositions/200?stage=2438)は、この短い前奏曲をマズルカとして捉え、旋律の素朴さと和声の繊細さを説明しています。湯気という抽象的な連想ではなく、その舞曲的な性格が伝わる、踊り出す前の二人を選びました。

[USCポーランド音楽センターの解説](https://polishmusic.usc.edu/research/dances/mazur/)が示すように、マズルにはさまざまな身振りや組み合わせがあります。この写真調の生成場面は、現代の控えめな練習室での静かな一瞬という映像解釈です。特定の歴史的な舞踏会や、唯一正しいマズルカの振付を再現したものではありません。

## 動き

顔、手、足、体の位置と床は固定し、スカートの布地の一部だけにごく弱い空気の動きを加えています。人物を実際に踊らせたり、録音と合う振付に見せたりはしません。カメラは固定し、縦長と横長のどちらでも二人を収めています。

録音の拍とは同期せず、動きを減らす設定では静止します。素材や描画機能が利用できない場合は、既存の代替描画に戻ります。
