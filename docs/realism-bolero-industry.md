# 《ボレロ》の Realism — 一定の駆動と機械の層

《ボレロ》は、小太鼓の変わらないリズムに二つの旋律が繰り返され、楽器と音色が積み重なっていく作品です。[フィルハーモニー・ド・パリの解説](https://pad.philharmoniedeparis.fr/0824129-bolero-de-maurice-ravel.aspx?_lg=fr-FR)は、反復と楽器の累積によるクレッシェンドを説明しています。[LA Phil の解説](https://www.laphil.com/works/bolero)には、ローラン＝マニュエルを通じて伝えられる工場との結び付きも紹介されています。

この場面では、イソギンチャクに代えて、同じ速さで回る円盤型プーリーと、その奥へ重なる機械の列を見せます。不変の駆動と奥行きの層を、反復と管弦楽の厚みに重ねた映像解釈です。特定の工場、作曲者が訪れた場所、初演の舞台を再現したものではありません。軸と革ベルトの構成は、[米国国立公園局の織機資料](https://home.nps.gov/articles/000/weave-room-frequently-asked-questions.htm)を機構の参考にしていますが、その施設とラヴェルの関係を示すものではありません。

## 動き

穴のない二枚の円盤面の質感を、同じ一定角速度で回転させます。窓からの大きな光の明暗は固定し、金属表面の模様と分けて扱います。わずかな遠近による楕円形に合わせた一定の投影を使い、半径ごとにねじる動きは加えません。円盤の輪郭、中央の軸受けとその影、軸の支え、ベルトの形、建物とカメラは固定し、革ベルトでは表面の細かな濃淡だけが走ります。速さを増してクレッシェンドに見せたり、録音の小太鼓に同期させたりはしません。

写真調の生成画像に局所的な動きを重ねた表現で、実写動画、工学シミュレーション、実際の工場の運転記録ではありません。動きを減らす設定では静止し、素材や描画機能を利用できない場合は既存の代替描画に戻ります。
