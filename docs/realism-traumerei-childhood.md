# トロイメライ — カッパドキアの朝、漂う気球

椅子と積木の室内から、トルコのカッパドキアをモチーフにした広い風景へ変更しました。淡い朝空、幾重にも続く谷、帽子状の岩を載せた奇岩の上を、遠近の異なる三つの気球がゆっくり漂います。

カッパドキアの侵食された尾根・谷・「妖精の煙突」と呼ばれる岩塔は、[ユネスコの地域解説](https://whc.unesco.org/en/list/357/)で確認できます。画像は地域の特徴に基づく想像上の合成景観で、特定の撮影地点を再現したものではありません。《トロイメライ》の穏やかな夢想に重ねた編集上の解釈であり、シューマンがこの土地を訪れた、またはこの景色から着想したという意味ではありません。

## 動き

地形、岩、空、カメラは固定しています。気球は背景とは分離した素材で、形を変えずにそれぞれ異なる速さで緩やかに横へ流れ、わずかに高度を変えます。岩と重ならない範囲に収め、縦長でも中央の気球と奇岩の奥行きが残ります。背景の全面移動や変形、明滅、拍への機械的な同期は使いません。

動きは共通の再生時刻に従います。停止・シーク・動きを減らす設定と従来の素材解放・代替描画を維持します。Visual、Impressive、選択音源は変更していません。
