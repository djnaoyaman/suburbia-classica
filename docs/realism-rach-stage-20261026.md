# ピアノ協奏曲第2番 第2楽章 — ピアノと木管の対話

ラフマニノフのこの楽章では、細やかに流れるピアノの伴奏の上に、フルートとクラリネットの旋律が歌います。[香港フィルの作品解説](https://www.hkphil.org/watch-and-listen/all-performances/rachmaninov-piano-concerto-no-2)が紹介するこの組み合わせを、Realism の中心に据えました。

静かな管弦楽の舞台で、閉じたグランドピアノを前景に、その奥の木管席にフルートとクラリネットを配置しています。空席だけでなく実際に旋律と伴奏を担う楽器を見せ、以前の魚のモチーフから、曲の響きに直接関わる情景へ変えています。

これは特定の公演、初演会場、演奏者を記録した写真ではなく、楽器の関係を示すために生成した舞台の構成です。鍵盤、指使い、楽譜を動かして演奏に見せかけることはしません。

楽器、椅子、譜面台、床、カメラは固定し、背景の幕のうち何も重なっていない部分だけをゆっくり動かします。共通の再生時刻に従い、停止・シーク・動きを減らす設定に対応します。音符との同期ではなく、静かな舞台の空気を保つための控えめな動きです。画像や描画機能を利用できない場合は従来の基本シーンへ戻ります。
