# 《天国と地獄》序曲 — フレンチカンカンの舞台

衣装だけを置いた舞台裏から、フレンチカンカンの華やぎを感じる劇場全体の情景へ変更しました。赤い幕、奥行きのある舞台、成人のプロの踊り手たちを、一つの公演場面として捉えています。

よく演奏される演奏会用序曲はカール・ビンダーによるもので、1858年版の短い導入曲や、オッフェンバック自身による後年の序曲とは区別されます。[Offenbach Edition Keck 校訂報告（PDF 7・27ページ）](https://www.boosey.com/downloads/Orphee58_CriticalReport_E.pdf)。序曲は有名な速い終結部だけでできているわけではありません。

終幕の《地獄のギャロップ》がカンカンの音楽として広く親しまれてきたことを、この場面の手がかりにしています。ただし、[英国国立オペラの解説](https://www.eno.org/discover-opera/articles/an-introduction-to-orpheus-in-the-underworld/)も区別するように、原作中のギャロップと、後に結びついたカンカンの踊りは同じものではありません。この画像は現代の架空の舞台を想定した編集上の解釈で、1858年の衣装・振付、特定の劇場や実在の公演の再現ではありません。

## 動き

人の身体、衣装、舞台床、建築、カメラは写真として固定しています。頭上に十分な距離を置いた舞台の薄い霞の内側だけが、緩やかに流れます。人をゴムのように変形させる動き、全画面の移動、露出の脈動は使いません。

共通の再生時刻、停止・シーク・動きを減らす設定、素材解放と従来の代替描画を維持しています。Visual、Impressive、選択音源は変更していません。
