# 《乾杯の歌》の Realism — サロンの二脚のグラス

《椿姫》第1幕の《乾杯の歌》は、ヴィオレッタのサロンの宴で歌われる、人生と愛への音楽の乾杯です。[シカゴ・リリック・オペラの解説](https://www.lyricopera.org/negaunee-education-programs/learning-resources/la-traviata/)と[メトロポリタン歌劇場の紹介](https://www.metopera.org/discover/video/?videoId=3930687970001)が、この場面と飲酒の歌としての性格を説明しています。

単独の水のグラスに代えて、談笑する人々を奥にぼかした夜のサロンと、卓上に並ぶ二脚のワイングラスを選びました。互いに歌い交わす華やかな乾杯を、酒と社交の場が分かる静物として表したものです。

グラスの縁、胴、脚、台座は動かさず、内側の小さな液面と灯の反射だけを控えめに変化させます。背景の人を歌わせたり、録音に口を合わせたりはしません。

写真調の生成画像を使った架空の舞台解釈で、実在の出演者、特定の上演、歴史的な写真ではありません。ワインの産地や銘柄も設定していません。動きを減らす設定では静止し、素材や描画機能を利用できない場合は既存の代替描画に戻ります。
