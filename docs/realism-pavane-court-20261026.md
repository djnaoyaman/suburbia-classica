# 《亡き王女のためのパヴァーヌ》の Realism

## 宮廷の舞曲として

貝殻と波の情景から、古いスペイン宮廷のゆっくりした舞いを想わせる衣装、足元、石床へ変更しました。銀青色の織物と金の縁取り、静かな光を受ける床を、写真調の生成画像で表現しています。

ラヴェルの説明として、昔のスペイン宮廷で王女が踊ったかもしれないパヴァーヌの追憶が紹介されています。特定の故人の葬送場面ではなく、この舞曲の性格を映像の出発点にしました。[香港フィルハーモニー管弦楽団の作品解説](https://www.hkphil.org/f/concert/25289/2425-w39a-TK-Ravel_E.pdf)（冊子3ページ、PDF4ページ）

これは作品から着想した映像解釈です。実在の王女、特定の宮殿、歴史上の舞踊や衣装を正確に再現した記録ではありません。

## 動きと表示

- 衣装の中央にある布の襞だけが、ゆっくりとごく小さく揺れます。裾の輪郭、靴、手、人物の輪郭、床と建築は固定しています。
- カメラは動かさず、縦長画面でも衣装の細部と足元を残します。
- 布の動きは48秒で連続する周期です。実際の振付や音符に同期した動きとはしていません。
- 再生画面の共通時刻と停止・動きを抑える設定に従います。別のタイマーは持ちません。
- 対応する描画機能や素材を利用できない場合は、従来の宮廷の燭台表現へ戻ります。

## 確認範囲

縦長・横長を含む5種類の画面比率について、ソフトウェア描画で素材の見え方、周期のつながり、固定部分が動かないことを確認しています。実機GPUの速度やすべてのブラウザーでの動作を保証するものではありません。
