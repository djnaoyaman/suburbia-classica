# ブラームス ワルツ第15番 — 誰もいない舞踏室

ピアノを中心に置いた室内から、床と光の広がりを感じられる、誰もいない優雅な舞踏室へ変更しました。寄木の床が奥の窓へ続き、柔らかな午後の光とカーテンが空間をつくります。人物、踊り手のシルエット、肖像画や彫像は入れていません。

[ヘンレ版の作品紹介](https://www.henle.de/Waltzes-op.-39/HN-1286)が述べる、この曲集の親密さと第15番の穏やかに揺れる旋律を、静かな踊りの場へ重ねた編集上の解釈です。画像は架空の室内で、ブラームスが演奏した実在の会場や、作曲時の部屋を再現したものではありません。

## 動き

窓辺の二か所のカーテンの内側だけを、微かな風が通る程度に動かします。床、建築、窓枠、シャンデリア、カメラ、光の明るさは固定です。全画面の変形や露出の脈動、音楽の拍への機械的な同期はありません。縦長でも空の床から窓へ続く奥行きが残ります。

共通の再生時刻、停止・シーク・動きを減らす設定、素材解放と代替描画を維持しています。Visual、Impressive、選択音源は変更していません。
