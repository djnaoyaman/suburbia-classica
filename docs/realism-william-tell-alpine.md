# 《ウィリアム・テル》序曲の Realism — 嵐の後の谷

[LA Phil の作品解説](https://www.laphil.com/works/william-tell-overture)は、静かな導入、嵐、その後の清新な田園場面という序曲の流れを紹介しています。オペラそのものはスイスの物語です。[ローザンヌ歌劇場の紹介](https://www.opera-lausanne.ch/en/show/william-tell/)

この場面では乾いた平原の砂旋風を、雨上がりの緑のアルプスの谷へ置き換えました。雲の切れ間と草地の広がりを、嵐の後に戻る田園の空気に重ねています。後年の西部劇との結び付きを作品本来の舞台と取り違えず、特定の山や展望地点を再現したとも主張しません。

山の稜線、谷、樹木とカメラは固定し、稜線から離れた上空の雲と手前の草だけを控えめに動かします。全曲の四つの部分を録音に合わせて再演する映像ではありません。

写真調の生成画像に局所的な動きを加えた表現で、実写動画や現地の気象記録ではありません。動きを減らす設定では静止し、素材や描画機能を利用できない場合は既存の代替描画に戻ります。
