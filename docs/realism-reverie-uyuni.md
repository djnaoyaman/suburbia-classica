# 夢 — 空と反射のあいだ

ドビュッシーの《夢（Rêverie）》は初期のピアノ独奏曲です。旋律のしなやかさを持つ親密な小品として紹介されています。[作品解説：G. Henle Verlag](https://www.henle.de/us/Reverie/HN-1721)

この映像では、夢想へ静かに漂うような聴感を、ウユニの空と水鏡に重ねました。上下に似た雲が広がり、空と地面の境界が曖昧になる一方、小さなさざ波が反射だけをわずかに変えます。これは当サイトによる映像解釈であり、作曲者の訪問、着想、作品に指定された情景を示すものではありません。

## モチーフ

ボリビアのウユニ塩原では、雨による薄い水の層が空を映す鏡面をつくることがあります。鏡面は一年中続くものではありません。この自然現象を参考に、空と反射のある写真調の景観を生成しました。[鏡面現象の解説：Copernicus Sentinel](https://sentinels.copernicus.eu/web/success-stories/-/sentinel-3-reveals-the-salar-de-uyuni-s-seasonal-transformation)

## 動きと限界

空、遠景、水平線、カメラは固定し、水に映った雲の部分だけに穏やかなさざ波を加えています。手前の塩の質感へ近づくほど動きは弱まります。画面全体のズーム、雲の大きな変形、音符に対応した動きは加えていません。

動きは既存の再生時間に従う 120 秒の連続ループです。一時停止や動きを抑える設定では静止します。実写動画や現地の観測記録ではなく、生成画像と局所的な描画効果による表現です。描画機能や素材を利用できない場合は、従来の簡易描画に戻ります。
