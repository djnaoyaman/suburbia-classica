# 《16のワルツ Op.39 第15番》の Realism

## 家庭で奏でるピアノのワルツ

水面を回る葉から、夕暮れの小さなピアノ・サロンへ変更しました。木目の美しいグランドピアノ、閉じた鍵盤蓋、幅の広いベンチ、暖かな室内灯と青い窓明かりを、写真調の生成画像で表現しています。

Op.39はもともとピアノ連弾の作品として書かれ、家庭での音楽として親しまれました。ブラームス自身による独奏版もあります。この編成と親密な演奏の場を、映像の出発点にしています。[ヘンレ原典版の序文](https://www.henle.de/media/ee/c6/8b/1737553002/1638.pdf)、[第15番の解説](https://www.henle.de/media/35/3a/fe/1697725904/1089-1697725904-sync.pdf)

サロンや楽器は作品から着想した映像解釈です。ブラームスの実際の部屋、愛用楽器、初演会場や特定の演奏を再現したものではありません。演奏の合間の静けさを想い、鍵盤蓋を閉じた姿にしています。奏者を描かず、録音と一致しない指の動きも加えていません。

## 動きと表示

- ピアノの奥にあるカーテンの一部分だけが、小さくゆっくり揺れます。楽器、鍵盤蓋、ベンチ、窓枠、室内の輪郭は固定しています。
- カメラは固定し、縦長画面でもピアノの木目、鍵盤蓋とペダルが残る構図を保ちます。
- 布の動きは60秒で連続する周期です。ワルツの拍や録音の音符に同期した動きではありません。
- 共通の再生時刻と停止・動きを抑える設定に従います。別のタイマーは使いません。
- 描画機能や素材が利用できない場合は、従来の琥珀色の舞踏室表現へ戻ります。

## 確認範囲

縦長・横長を含む5種類の比率をソフトウェア描画で確認し、周期のつながりと、固定部分が動かないことを検査しています。実機GPUの速度やすべてのブラウザーでの動作を保証するものではありません。
