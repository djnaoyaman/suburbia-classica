# 主よ、人の望みの喜びよ — 朝の光と祈り

バッハのカンタータ BWV 147 の終結コラールは、イエスを心の慰め、生きる力として歌います。その精神的な喜びを、静かな石造の聖堂と朝の光で表現しました。[歌詞と作品解説：Netherlands Bach Society](https://www.bachvereniging.nl/en/bwv/bwv-147)

この教会は生成画像による架空の祈りの空間です。バッハゆかりの特定の建物、初演の会場、歴史的な礼拝の再現を示すものではありません。

## 動き

窓、十字架、長椅子、石の輪郭、カメラは動かしません。窓から差す光の範囲に限り、ごく小さな塵がゆっくり漂い、空気中の明るさが穏やかに変化します。光の粒が輝きながら飛び回る演出ではなく、静かな室内の自然な動きを目指しています。

動きは既存の再生時間に従う 120 秒の連続ループです。一時停止や動きを抑える設定では、その時間の画面が静止します。音符ごとの動きや演奏に同期した振付を表すものではありません。

## 表現の限界

実写動画ではなく、写真調の生成画像に局所的な光と塵の動きを加えた表現です。画面比率によって周囲の柱や長椅子はトリミングされます。描画機能や素材を利用できない場合は、従来の「聖堂の窓から差す朝の光」の表現に戻ります。
