# 《パガニーニの主題による狂詩曲》第18変奏 — 窓とその反射

ラフマニノフの第18変奏では、パガニーニの短調の主題が反転され、長調の旋律になります。[LA Phil の作品解説](https://www.laphil.com/works/rhapsody-on-a-theme-of-paganini)がこの変化を説明しています。

鳥の群れではなく、雨上がりの中庭で、実際の窓と水面に上下逆に映る窓を一緒に見せました。同じ形が向きを変えることで違う表情になる、という映像上のたとえです。音程の反転を図解するものではなく、反射が長調・短調そのものを表すという意味でもありません。作曲者がこの中庭を訪れたり、ここで着想したという主張はしていません。

## 見え方と動き

大きな湖や遠景の絶景ではなく、濡れた石畳と窓を近い視点から捉えた写真調の生成解釈です。特定の建物の記録写真ではありません。実際の窓、壁、石畳、カメラは固定し、浅い水たまりの内側だけに細かな波の動きを加えています。縦長画面でも実際の窓と反射した窓を上下に見ることができます。

録画映像や流体の物理シミュレーションではなく、生成画像に局所的な動きを重ねています。録音の拍には同期せず、動きを減らす設定では静止します。素材や描画機能を使えない場合は、既存のヴァイオリンの弦を表す代替描画に戻ります。
