# 夜の女王のアリア — 月光の山壁と深い峡谷

熾火を近くから見る画面に代えて、冷たい月光を受ける峻厳な山壁と、幾重もの稜線の間へ沈む深い峡谷を描きました。人物や王冠を置くのではなく、風景の高さと陰影によって、夜の女王の威厳と激しさを表す編集上の解釈です。

[ロイヤル・オペラの作品解説](https://www.rbo.org.uk/opera-essentials-the-magic-flute)は、夜の女王を力を持つ支配者として紹介し、このアリアをパミーナへ復讐を命じる場面と説明しています。ここでの山岳風景は、その劇的な力を自然の規模へ置き換えたものです。実際の舞台装置、特定の国の山、モーツァルトの旅行先や作曲地を再現したものではありません。

## 動き

山壁、岩、峡谷、光、カメラは固定し、岩の稜線から離れた夜空の薄い雲だけをゆっくり動かします。月そのものは画面に置かず、流星、火花、稲妻、明滅は使いません。縦長でも明るい山壁と暗い谷の奥行きが残る構図です。

共通の再生時刻、停止・シーク・動きを減らす設定、素材や描画機能が利用できない場合の代替描画を保ちます。音源、Visual、Impressive、他の曲は変更していません。
