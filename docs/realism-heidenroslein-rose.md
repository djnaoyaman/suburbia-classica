# シューベルト《野ばら》の Realism — 赤い花と棘

この曲はシューベルト《野ばら》D257／Op.3 第3番です。ゲーテの詩に作曲された声とピアノの歌曲であることは、[オーストリア科学アカデミーの作品目録](https://schubert-digital.acdh-dev.oeaw.ac.at/W-00197.html)で確認できます。

ゲーテの歌詞には、野に咲く赤いばらと、摘もうとする相手に刺して抵抗する花が登場します。虫ではなく、その花自身を主役に、一輪の赤い花、棘のある茎、周囲の草を描きました。[Oxford Song の原語テキスト](https://oxfordsong.org/song/heidenr%C3%B6slein-3)を参照しています。同ページはギター編曲の見出しですが、ここでは歌詞の確認に用いており、このサイトの録音がその編曲だと示すものではありません。

## 見え方と動き

幾重にも重なる花束ではなく、薄い花弁が開いた素朴な一輪を写真調で表現しています。特定の植物種・品種を同定した画像や、詩の場所を再現した写真ではありません。人物や虫、花を摘む行為は描きません。

花の中心、茎、棘、葉とカメラは固定し、花弁の内側と近くの草の一部だけに弱い風の動きを加えています。花全体が膨らむ、急に開く、茎が伸びるような変形はありません。縦長画面でも花と棘のある茎が残る構図です。

生成画像に局所的な動きを重ねた表現で、実写動画や植物の物理シミュレーションではありません。動きは録音の拍に同期せず、動きを減らす設定では静止します。素材や描画機能を利用できない場合は、既存の朝露の野ばらを表す代替描画に戻ります。
