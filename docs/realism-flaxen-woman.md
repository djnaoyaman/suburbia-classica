# 亜麻色の髪の乙女 — 花咲く草地と遠い海

人物の肖像に代えて、淡い穂と小さな花が広がる海辺の草地、青緑の海、低い島影へと続く風景にしました。乙女を大きく描くのではなく、そこに人がいても自然に感じられる空間を主役にしています。素朴で柔らかな旋律の印象を、光と風と見晴らしへ重ねた編集上の解釈です。

[ヘンレ版の序文](https://www.henle.de/media/e9/36/85/1697725790/1319-1697725790-sync.pdf)は、題名をルコント・ド・リールの同名詩と、そのスコットランド歌曲の系譜に結びつけています。[詩の本文](https://rpo.library.utoronto.ca/content/la-fille-aux-cheveux-de-lin)には、花咲く草地と夏の光が現れます。海岸や島は、そこから広げた風景の解釈であり、詩に記された具体的な海岸を再現したものではありません。ドビュッシーの旅行先や作曲地を示す画像でもありません。

## 動き

手前の草の一部には小さな風、岩や岸から離れた海面には細かな波、陸地より高い空にはゆっくりした雲の動きを重ねます。地形、岩、水平線、カメラは固定し、全画面の変形や光の明滅は使いません。

共通の再生時刻、停止・シーク・動きを減らす設定、素材や描画機能が利用できない場合の代替描画を保ちます。縦長でも草地・海・空が重なる構図です。音源、Visual、Impressive、他の曲は変更していません。
