# BWV 846 の Realism — 分散和音を支える弦

[オランダ・バッハ協会の解説](https://www.bachvereniging.nl/en/bwv/bwv-846)は、この前奏曲の特徴を、長く連なる分散和音として説明しています。鍵盤作品の物理的な響きに立ち戻り、蜘蛛の糸ではなく、整然と並ぶチェンバロの弦と木の響板を選びました。

音が次々にほどけながら和声のまとまりを保つことを、平行な弦の反復と、その下に広がる一枚の響板に重ねた映像解釈です。鍵盤を自動演奏させたり、録音に合うように弦を振動させたりする表現ではありません。

構造の参考には、[メトロポリタン美術館のチェンバロ資料](https://www.metmuseum.org/art/collection/search/501787)を参照しました。映像の楽器は写真調の生成物で、同館の実物、バッハの所有楽器や録音で使われた楽器そのものではありません。現在の選択音源と、映像で扱う歴史的鍵盤楽器のイメージは区別しています。

## 動き

弦、駒、響孔と外枠の形を固定し、窓辺の弱い光の変化と少量の浮遊塵だけを加えています。木や弦が波打つような歪みはなく、カメラも動きません。縦長画面でも弦と響板を近くに見る固定構図です。

録音の拍とは同期せず、動きを減らす設定では静止します。素材や描画機能が利用できない場合は、既存の代替描画に戻ります。
