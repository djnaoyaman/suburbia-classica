# 夜想曲第20番の Realism — 夜の窓

[ショパン研究所の姉ルドヴィカの解説](https://chopin.nifc.pl/en/chopin/osoba/616_jedrzejewiczowa_ludwika)は、1830年にショパンがこの曲を姉へ送ったことと、「夜想曲の形式によるレント」という位置づけを伝えています。ここでは後世の映画や特定の悲劇の場面を再現せず、夜想曲としての静かに歌う性格を出発点にしました。

暗い部屋から見る遠い街の灯と、すぐそばの柔らかな布。隔たりのある二つの距離を、長く保たれる旋律とその周囲の細やかな響きに重ねています。夜の情景は映像上の解釈であり、ショパンの実際の部屋、特定の都市や作曲の夜を示すものではありません。

## 動き

窓枠、街並み、灯、カメラは固定し、薄いカーテンの一部だけを弱い風で動かしています。夜景全体が揺れたり、灯が拍に合わせて明滅したりはしません。写真調の生成素材を使用し、縦長画面でも布と遠景を同時に見られる固定構図です。

録音の拍とは同期せず、動きを減らす設定では静止します。素材や描画機能が利用できない場合は、既存の代替描画に戻ります。
