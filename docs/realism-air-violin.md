# 《G線上のアリア》の Realism — 回廊と水の庭園

ヴァイオリンの接写から、回廊、庭園、静かな池が奥へ続く風景へ改めました。[オランダ・バッハ協会の作品解説](https://www.bachvereniging.nl/en/bwv/bwv-1068)は、《管弦楽組曲第3番》に流れる宮廷舞曲の様式と、Airにおける第2ヴァイオリンとヴィオラの繊細な対話を説明しています。左右の建築と、距離を隔てて重なる庭や反射を、その均衡と歌のつながりに重ねた編集上の解釈です。

これは特定の宮殿や、バッハが訪れた庭、作曲や初演の場所を再現したものではありません。[ボストン交響楽団の解説](https://www.bso.org/works/bach-air-from-orchestral-suite-no-3)も、組曲の正確な成立事情や演奏機会が判明していないことに触れています。「G線上」という通称は後世のウィルヘルミによるヴァイオリン編曲に由来し、原曲全体を一本の弦で奏するという意味でもありません。

## 風景と動き

写真調に生成した想像の庭園です。カメラ、石の縁、回廊、樹木、空は固定し、池の内側に映る反射だけを小さな波で動かします。手前ほど少し大きくなる波を重ね、石の境界では変位をゼロにします。画面全体をゆがめたり、明滅させたりする効果ではありません。

横長では左右の回廊から庭へ、縦長では水面から遠いアーチ、丘、空へ視線が続きます。共通の再生時刻に従い、停止・シーク・動きを減らす設定では同じ時刻の画面を保ちます。選択音源、Visual、Impressiveは変更していません。写真素材や描画機能を利用できない場合は従来の代替描画を使います。
