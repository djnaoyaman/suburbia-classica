# 《亜麻色の髪の乙女》の Realism — 題名の人物へ

[ヘンレ原典版の序文](https://www.henle.de/media/e9/36/85/1697725790/1319-1697725790-sync.pdf)は、1910年のピアノ前奏曲の題名がルコント・ド・リールの同名詩を参照することを説明しています。ドビュッシーはそれ以前にも同じ詩を歌曲にしていますが、序文は前奏曲を独立した作品として区別しています。この映像も、歌曲の実演や特定の歌手の肖像ではありません。

草穂との色だけの連想をやめ、題名の髪を持つ成人女性を、静かな草地で想像しました。後ろ寄りの横顔と柔らかな髪の流れを、穏やかで簡潔な旋律に重ねる人物解釈です。実在するモデル、作曲者の恋人、作品の決まった主人公を特定したものではなく、背景も特定の土地ではありません。

## 動き

顔、目、閉じた口、頭部の位置、姿勢とカメラは固定し、顔から離れた下側の毛先と衣服の一部だけを微風のように小さく動かします。瞬き、口の動き、歌唱や演奏の同期は付けていません。縦長画面では横顔と髪を中心に、横に広い画面では頭部を切らない固定の構図調整を行います。

写真調の生成人物で、実在人物の記録映像ではありません。髪や布の動きも局所的な映像表現で、身体や髪の物理シミュレーションではありません。動きを減らす設定では静止し、素材や描画機能を利用できない場合は既存の草原の代替描画に戻ります。
