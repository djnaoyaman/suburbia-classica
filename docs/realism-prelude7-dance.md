# 前奏曲第7番 — 春の果樹園から村の緑へ

室内の二人から、春の果樹園が小さな村の緑へ開ける風景に変更しました。花をつけた果樹の枝、手前の柔らかな草、奥の家並みと曲がる小道を、一つの空間として見せています。

[ショパン研究所による作品紹介](https://artsandculture.google.com/story/symbols-and-imagination-narodowy-instytut-fryderyka-chopina/TwUxx7PabkyL1g?hl=en)は、第7番を短く優雅なマズルカの小品として説明しています。その素朴さ、軽やかさ、均衡を、明るい春の田園へ重ねた編集上の解釈です。同ページで紹介される画家の作品を再現したものではなく、ショパンが訪れた村や、作曲の着想となった景色を特定するものでもありません。

## 動き

前景の草地の内側だけに、穏やかな風の揺れを加えています。果樹の幹と花枝、石垣、小道、家並み、カメラ、全体の明るさは固定しています。縦長でも花の枝、開けた草地、奥の村が残ります。全画面の変形、露出の脈動、録音の拍への機械的な同期はありません。

共通の再生時刻、停止・シーク・動きを減らす設定、素材解放と代替描画を維持しています。Visual、Impressive、選択音源は変更していません。
