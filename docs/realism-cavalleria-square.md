# 《カヴァレリア・ルスティカーナ》間奏曲の Realism — 人のいない広場

マスカーニのオペラは、復活祭のシチリアの村が舞台です。[スカラ座公開の台本](https://www.teatroallascala.org/static/upload/cav/cavalleria-rusticana-il-libretto.pdf)には教会のある広場が示され、二人の登場人物が去ったところに間奏曲が置かれています。[LA Phil の解説](https://www.laphil.com/works/intermezzo-from-cavalleria-rusticana-mascagni)も、この時の無人の広場と、教会で先に聞こえた聖歌とのつながりを説明しています。

そこで、貝ではなく、人のいない石畳の広場と教会の扉を描きました。礼拝の静けさと、その後の悲劇の間にあるひとときを、空いた空間で受け止める映像解釈です。特定の実在する村や教会、初演の舞台、歴史的な実写を再現したものではありません。

## 動き

扉、建物、石畳とカメラは固定し、画面端の葉の小さな揺れと、手前の石畳に落ちる木漏れ日の濃淡だけを変化させています。石の模様を動かすのではなく、光の変化を重ねるため、地面が波打つ表現にはしません。縦長画面では教会の入口と無人の前庭を中心に見せます。

写真調の生成画像に局所的な動きを重ねたもので、実写動画や光の物理シミュレーションではありません。録音の拍と同期せず、動きを減らす設定では静止します。素材や描画機能を利用できない場合は、既存の村の聖堂を表す代替描画に戻ります。
