# 《荒城の月》の Realism — 月と残された石垣

《荒城の月》は土井晩翠の詞と滝廉太郎の旋律による歌です。[仙台文学館](https://www.sendai-lit.jp/5587)は、1901年の『中学唱歌』への掲載を紹介しています。[日本ペンクラブ電子文藝館に掲載された原詞](https://bungeikan.japanpen.or.jp/1941/)では、時代の移ろいに対する月の変わらぬ光、荒れた城に残る蔓、風を受ける松が描かれます。

そこで、フクロウではなく、月と、蔓の残る石垣、松を中心にしました。変わらず照らす月と、栄枯の跡をとどめる地上を対比する、歌詞に基づく映像解釈です。青葉城・鶴ヶ城・岡城など特定の城跡の復元や実写ではなく、作詞・作曲の場所を示すものでもありません。丸い月の形は画面上の選択で、原詞が月齢を指定しているという意味ではありません。

## 動き

月、空、石垣、松の幹とカメラは固定し、手前の草の小さな揺れと、蔓の葉に当たる光の弱い明暗だけを重ねています。石の形や模様を流したり、月を拡大・移動させたりはしません。縦長画面では月と蔓のある石垣を中心に見せ、右端の松は画面外になる場合があります。

写真調の生成画像による想像上の夜景で、実写動画や厳密な月光の物理シミュレーションではありません。録音の拍とは同期せず、動きを減らす設定では静止します。素材や描画機能を利用できない場合は、既存の石垣と月の代替描画に戻ります。
