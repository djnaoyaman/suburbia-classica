# 《新世界より》ラルゴの Realism — 道の先の灯

この情景は、原曲の筋書きではなく、後世の《Goin’ Home》としての受け止め方に基づいています。[シブリー音楽図書館が所蔵する1922年版](https://urresearch.rochester.edu/institutionalPublicationPublicView.action?institutionalItemVersionId=18093)は、ウィリアム・アームズ・フィッシャーによる作詞・編曲を明記しています。ドヴォルザークが古い《Goin’ Home》を引用した、という関係ではありません。

[ドヴォルザーク作品資料](https://www.antonin-dvorak.cz/en/work/symphony-no-9/)は、原曲ラルゴの主旋律をコーラングレが歌い、弱音器付きの弦が支えること、そして後のフィッシャーの編曲を説明しています。この長い旋律を、道の先にある帰る灯をじっと見つめる構図に、持続する伴奏の穏やかな広がりを、周囲の草と高い薄雲の小さな動きに重ねました。これは音楽から受ける感情の映像解釈であり、音符との一対一対応や厳密な拍同期ではありません。

鹿の代わりに描いたのは、夕暮れの小道と一軒の窓灯です。特定の国、作曲者の家、旅先の記録や原曲の着想を示してはいません。《Goin’ Home》の精神的な意味全体を、日常の帰宅だけに限定するものでもありません。

## 動き

家、窓灯、道、遠景の輪郭とカメラは固定し、道脇の草と高い薄雲だけをゆっくり動かします。縦長画面でも、道から家の灯へ向かう視線を保ちます。窓を点滅させたり、カメラが家へ進んだりはしません。

写真調の生成画像と局所的な動きによる想像上の風景で、実写動画や特定の土地の再現ではありません。動きを減らす設定では静止します。素材や描画機能を利用できない場合は、既存の夕景の代替描画に戻ります。
