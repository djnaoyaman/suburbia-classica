# 《展覧会の絵》の Realism — 絵のあいだを歩く

[LA Phil の作品解説](https://www.laphil.com/works/pictures-at-an-exhibition)は、ハルトマンの追悼展から生まれた組曲と、絵から絵へ歩く姿を表す《プロムナード》の関係を説明しています。

ここでは無関係な鍾乳洞を、異なる額装スケッチと歩くための余白がある画廊へ置き換えました。窓の昼光の中で複数の絵を眺める場面は、作品全体の「見る・歩く・また見る」という経験への映像解釈です。

室内も絵も新たに生成した架空のものです。ハルトマンの真正な作品、実際の追悼展、現存の美術館を再現した画像ではなく、架空の作品名や読めるキャプションも付けていません。

額、絵、壁、床板とカメラは動かさず、窓からの光の弱い変化と少数の細かな塵だけを加えています。写真調の生成画像を用いた表現であり、実写の美術館映像ではありません。動きを減らす設定では静止し、素材や描画機能を利用できない場合は既存の代替描画に戻ります。
