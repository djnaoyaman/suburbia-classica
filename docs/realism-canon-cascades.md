# カノン — 段をつなぐ流れ

パッヘルベルの《カノン》では、2 小節の低音の型が繰り返され、その上で三つのヴァイオリンが模倣し合います。[原典版の作品解説：G. Henle Verlag](https://www.henle.de/en/Canon-and-Gigue-D-major-for-three-Violins-and-Basso-continuo/HN-963)

この「繰り返す基盤の上で、流れが次へ受け渡される」という構造を、動かない岩の段と、複数の水盆を連続してつなぐ滝に重ねました。単に穏やかな水を見せるのではなく、縦長画面でも三段のつながりが読める構図にしています。

## モチーフ

クロアチアのプリトヴィツェ湖群では、石灰華の堰が湖を分け、その湖々を滝がつないでいます。この地形的特徴を参考にした生成景観です。[地形の解説：プリトヴィツェ湖群国立公園](https://np-plitvicka-jezera.hr/en/natural-and-cultural-heritage/natural-heritage/tufa/creator-of-waterfalls-and-lakes/)

場所の選択は当サイトによる映像上の解釈です。パッヘルベルの訪問や着想、曲とこの場所の歴史的関係を示すものではなく、特定の撮影地点の記録でもありません。

## 動きと限界

カメラ、森、岩の形、段の輪郭は固定します。白い水流の細かな明暗が下向きに移り、水盆の内部だけに小さなさざ波が生じます。滝が逆流したり、地形全体が伸び縮みしたりする演出は加えていません。

動きは既存の再生時間に従う 120 秒の連続ループで、一時停止や動きを抑える設定では静止します。三段の滝や水の速さは、声部の入りや音符を正確に描き起こしたものではありません。実写動画ではなく、写真調の生成画像に局所的な描画効果を加えた表現です。素材や描画機能を利用できない場合は、従来の三本の弦の表現に戻ります。
