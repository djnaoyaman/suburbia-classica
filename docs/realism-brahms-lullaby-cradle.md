# ブラームス《子守歌》の Realism — 安らかな夜の寝床

《子守歌》Op.49 第4番の歌詞には、夜の挨拶、バラ、掛け物の下で休むこと、穏やかな眠りへの願いが登場します。この映像では、その言葉を小さな木の寝床と柔らかなリネン、傍らの一輪のバラに置き換えました。歌詞は [Hampsong Foundation の原語テキスト](https://hampsongfoundation.org/resource/johannes-brahms/)で確認できます。

これは子守歌の言葉に基づく生成画像の映像解釈です。ブラームスの住居や、特定の子供の部屋を再現したものではありません。人物は描かず、空の寝床を静かな夜の象徴として置いています。縦長画面では寝床と窓辺の布を中心に切り取ります。

## 動き

窓辺の薄いカーテンの内側だけに、弱い風による小さな布の動きを加えています。寝床、リネンの寝具、木の桟、窓枠、バラとカメラは固定し、寝床が呼吸するような変形や大きな揺れは加えません。再生位置から同じ静かな動きが再現され、動きを減らす設定では静止します。

写真調の生成素材に局所的な動きを重ねた表現で、実写動画や布の物理シミュレーションではありません。録音の拍に同期して動かすものでもありません。対応する描画機能や素材を利用できない場合は、既存の夜の室内を表す代替描画に戻ります。
