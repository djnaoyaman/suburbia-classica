# 《トロイメライ》の Realism — 子供時代を思い返す窓辺

[ヘンレ原典版《子供の情景》の序文](https://www.henle.de/media/66/7d/8a/1690886059/0044-1690886059-sync.pdf)は、シューマンが1848年のライネッケ宛書簡で、この曲集を大人による大人のための回想として説明したことを紹介しています。子供が演奏する可能性まで否定する意味ではありません。また、[同社の《トロイメライ》論考](https://www.henle.de/media/0a/2b/f0/1687445046/essay_traeumerei.pdf)は、題名を深い睡眠ではなく、ふと心が遊ぶ白昼夢・夢想として捉えています。

この違いから、眠る子供や寝台ではなく、小さな木椅子と床に残された積木を選びました。大人の視線が幼い頃の遊びの跡に立ち止まる、明るい回想の情景です。漂う種子への抽象的な連想よりも、曲集の子供時代という主題が見える構図にしています。

椅子や積木は映像のために選んだ小道具で、シューマン自身の部屋、所有していた玩具、曲が生まれた実際の場面を示してはいません。空いた椅子も、死別や喪失の物語を意味するものではありません。

## 動き

椅子、四つの積木、窓枠、床とカメラは固定し、カーテンの一部と少量の浮遊塵だけが、部屋を通る弱い空気を表します。椅子を揺らしたり、積木を勝手に動かしたりはしません。縦長画面でも椅子と積木を保つ固定の構図調整を行います。

写真調の生成画像に局所的な動きを加えたもので、歴史的な実写や布の物理シミュレーションではありません。録音の拍とは同期せず、動きを減らす設定では静止します。素材や描画機能を利用できない場合は、既存の綿毛の代替描画に戻ります。
