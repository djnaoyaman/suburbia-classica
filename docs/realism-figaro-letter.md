# 《フィガロの結婚》手紙の二重唱の Realism — 庭を望む書き物机

第3幕の「手紙の二重唱」では、伯爵夫人が口述し、スザンナが手紙をしたためます。手紙を留めるピンは、のちに逢い引きの合図として返される小道具でもあります。[シカゴ・リリック・オペラの公演プログラム](https://s3.amazonaws.com/lyricoperamedia/programs/2024_TheMarriageOfFigaro/TheMarriageOfFigaroProgram.pdf)のあらすじで、この手紙とピンの役割を確認できます。

枝に下がる二つの種子ではなく、劇中で二人が一緒に作る手紙そのものを主題にしました。畳まれた紙、その手前で留めるのを待つ一本のピン、羽根ペンとインク。庭を望む窓辺に置いた、封をする直前を想像した静物です。手紙の場面そのものを庭の中とするのではなく、その先の約束を背景の庭に重ねています。

声が応じ合いながら一通の手紙を仕上げる親密さを、小さな紙と窓を通るそよ風で受け止めます。紙の内側の文面は見せず、架空の読み取れる文字やモーツァルトの筆跡は作りません。机、庭、筆記具の具体的な形は映像のために選んだ小道具で、実在の手紙や特定上演の記録ではありません。

## 動き

紙、ピン、羽根ペン、インク壺、机とカメラは固定します。カーテンの一部と窓の外の葉だけが、弱い風でゆっくり揺れる構成です。勝手に文字を書いたり、ピンや紙が浮いたりはしません。縦長画面では手紙の中央とピンを中心に見せ、横長では窓辺と筆記具まで広く見せます。

写真調の生成画像に局所的な動きを加えたもので、実写動画や布の物理シミュレーションではありません。録音の拍とは同期せず、動きを減らす設定では静止します。素材や描画機能を利用できない場合は既存の代替描画に戻ります。
