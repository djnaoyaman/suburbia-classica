# 愛のあいさつ — 川辺の道と石灰岩の丘

手紙とリボンの静物に代えて、牧草地と石灰岩の丘の間を川がめぐり、その岸に細い道が続く風景にしました。親密な旋律の柔らかさと、少し先へ向かう感覚を、温かな光と流れの奥行きへ重ねた編集上の解釈です。

[エルガーの作品解説](https://www.elgar.org/3salut.htm)は、この曲をアリスへの贈り物と、ヨークシャーのセトル滞在に結びつけています。ここではその地域を風景の手がかりにしていますが、曲の正確な成立地点や、特定の眺めが作曲を引き起こしたという意味ではありません。画像は想像上の合成景観で、エルガーが実際に立った場所の再現でもありません。

石灰岩の露頭、牧草地、石積みの壁、川辺の木々は、[ヨークシャー・デイルズ国立公園の景観資料](https://www.yorkshiredales.org.uk/wp-content/uploads/sites/13/2019/09/LCA-combined-files-final-report.pdf)に見られる地域的な要素を参考にしています。実在する一点の観光写真としては扱いません。

## 風景と動き

岸、露出した石、草、丘、カメラは固定し、石や岸から離れた水面の内側だけに小さな流れと波を重ねます。全画面のゆがみや明滅、演奏の拍への同期は使いません。縦長でも、川と丘の層が残るように構図を保ちます。

共通の再生時刻に従い、停止・シーク・動きを減らす設定に対応します。選択音源、Visual、Impressiveは変更していません。素材や描画機能を利用できない場合は従来の代替描画に戻ります。
