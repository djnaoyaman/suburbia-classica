# 《G線上のアリア》の Realism — 弦と木肌

「G線上」という通称は、バッハの原曲に付いた演奏指示ではありません。[ボストン交響楽団の解説](https://www.bso.org/works/bach-air-from-orchestral-suite-no-3)は、アウグスト・ウィルヘルミの1871年のヴァイオリン編曲で、旋律を低く移して最低音のG線で弾けるようにしたことを説明しています。一方、[オランダ・バッハ協会](https://www.bachvereniging.nl/en/bwv/bwv-1068)は、原曲のAirにおける第2ヴァイオリンとヴィオラの繊細な対話に触れています。

この原曲の弦の歌と、後世の通称に由来する具体的な弦を、ヴァイオリンの駒と木肌へ寄る静物として表しました。クラゲの動きではなく、音を生む素材そのものを見つめる解釈です。原曲全体が一本のG線だけで演奏されるという意味ではなく、特定の歴史的楽器や、現在の録音で使われた楽器の写真でもありません。

## 楽器と動き

[ヤマハの楽器解説](https://www.yamaha.com/en/musical_instrument_guide/violin/mechanism/mechanism002.html)が示すように、ヴァイオリンには高音からE・A・D・Gの四本の弦があります。画面では四本が駒を越えて尾部へつながり、太い低音側から木肌を見る構図にしています。

弦、駒、胴、カメラはすべて固定し、上側の木肌に当たる弱い光と、ごく少量の浮遊塵だけを動かします。無人の弓や弦を演奏しているようには動かさず、録音の拍とも同期させません。縦長画面では四本の弦と駒を中心に見せるため、胴の左右は画面外になります。

写真調の生成静物に局所的な光の表現を加えたもので、実写演奏動画や楽器の物理シミュレーションではありません。動きを減らす設定では静止し、素材や描画機能を利用できない場合は既存の弦と木肌の代替描画に戻ります。
