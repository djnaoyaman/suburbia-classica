## Verification

Arabesque's crossing residuals are checked across the sequence. A narrow offscreen-root culling discontinuity was found and removed; an exact-event regression test covers the formerly affected visible crossing. Integration tests compare all sixteen sources against native wrapped rendering and retain pause, seek, reduced-motion, unavailable-mode and late-image guards. Desktop live checks follow deployment.

Dense contours can produce local shimmer; no physical-device FPS, universal comfort or medical-safety certification is implied. A geometrically valid crossing alone is not the visual-quality gate: actual normal-phone-size time sequences are independently inspected.
