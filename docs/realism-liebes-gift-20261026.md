# 愛のあいさつ — 詩と音楽の贈り物

《愛のあいさつ》のもとの題名は《Liebesgruss》。[エルガー協会の作品解説](https://www.elgar.org/3salut.htm)によれば、1888年、アリスが贈った詩に応えて、エルガーは彼女へこの短い曲を書きました。

この Realism は、その親密なやり取りを、閉じた手紙とリボンで結んだ小さな楽譜綴りに託しています。紙、包装、机、庭は映像のために構成した生成の情景で、実物の原稿、特定の贈呈場所、歴史的な一場面の再現ではありません。詩や楽譜の文字も捏造して描いていません。

紙の輪郭、綴じ目、結び目、机、カメラは固定し、短いリボンの先の周辺だけに小さな風の動きを加えています。光の変化も局所的で穏やかです。手渡しや演奏を装う動きはありません。

共通の再生時刻に従って停止・シーク・動きを減らす設定に対応します。演奏の音符と同期した動きではなく、控えめに繰り返す情景です。画像や描画機能を利用できない場合は従来の基本シーンへ戻ります。
